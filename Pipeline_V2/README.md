12/10/2026 Version 2 Pipeline progression

Overview:

An internal service planning team in a community healthcare organisation has requested:

"We need a dependable combined data set from the public sources we've identified. Our analysts want to explore how population, deprivation, and care needs vary by area, and then compare those with our workforce information where it's possible." 

Plan:
Create well-structured and documented data that they can actually trust. 
Check what each source represents
Build a small repeatable pipeline for an initial compatible subset. 
It should land cleanly in raw, then is cleaned into staging, and prepared tables with notes. 
Quality checks (missing data, duplications, unstable joins)
Tests.
